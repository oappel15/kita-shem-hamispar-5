# Kita · שם המספר · כיתה ה׳

מצגת אינטרנטית לשיעור שפה (חינוך לשוני) בכיתה ה׳ על שם המספר: זכר ונקבה, 1 ו־2, שלושת הספרים, מונה וסודר, מספר סתמי ותאריך, טעויות נפוצות.

- `index.html` – המצגת (16 שקופיות, ניווט במקלדת, בלחיצה ובהחלקה, שעון לשלב, הערות למורה).
- `teacher.html` – אזור המורים (קוד מורה): תוכנית זמנים, מפתח תשובות, רקע לשוני, הערות לכל שקופית.
- `handout.html` – דף עבודה להדפסה.

לפי תוכנית הלימודים של משרד החינוך: https://meyda.education.gov.il/files/Curriculum/hebrew-1-6.pdf (עמ׳ 67, 90).
נבנה עם Kita. אתר סטטי, ללא שלב build.
